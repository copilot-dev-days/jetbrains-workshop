# Primeiros passos com GitHub Copilot (JetBrains)

Projetado para ser seu programador par com IA, o [GitHub Copilot](https://github.com/features/copilot) ajuda você a gerar código e focar no que é importante. Neste workshop de uma hora, você usará o **IntelliJ IDEA** + **Copilot for JetBrains** para entender e estender uma aplicação real Spring Boot.

Este workshop utiliza a aplicação de exemplo **Spring PetClinic**.

Você trabalhará em um clone local de: https://github.com/spring-projects/spring-petclinic

## Pré-requisitos

> [!NOTE]
> Em caso de dúvida, selecione o código e peça ao Copilot Chat para explicá-lo.

Você precisará de:

- Uma conta GitHub e acesso ao GitHub Copilot
- IntelliJ IDEA (Community ou Ultimate)
- Git
- Java 17+
