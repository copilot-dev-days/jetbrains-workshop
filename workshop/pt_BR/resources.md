# Recursos do GitHub Copilot (foco em JetBrains)

- Página do produto GitHub Copilot: https://github.com/features/copilot
- Instalar o Copilot na sua IDE: https://docs.github.com/en/copilot/managing-copilot/configure-personal-settings/installing-the-github-copilot-extension-in-your-environment
- Copilot Chat cookbook: https://docs.github.com/en/copilot/copilot-chat-cookbook
- Instruções personalizadas para o Copilot: https://docs.github.com/en/copilot/customizing-copilot/adding-repository-custom-instructions-for-github-copilot
- Engenharia de prompts / criação de prompts: https://docs.github.com/en/copilot/getting-started-with-github-copilot/learning-to-use-github-copilot

> [!NOTE]
> Os rótulos da interface do JetBrains podem variar conforme a versão da IDE e do plugin. Se o nome de um botão for diferente, use o equivalente mais próximo (por exemplo "Copilot Chat", "Chat" ou a janela de ferramentas com o ícone do Copilot).
