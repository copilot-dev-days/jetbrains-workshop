# Primeros pasos con GitHub Copilot (JetBrains)

Diseñado para ser tu programador en pareja con IA, [GitHub Copilot](https://github.com/features/copilot) te ayuda a generar código y a concentrarte en lo importante. En este taller de una hora usarás **IntelliJ IDEA** + **Copilot for JetBrains** para comprender y extender una aplicación real de Spring Boot.

Este taller utiliza la aplicación de ejemplo **Spring PetClinic**.

Trabajarás en un clon local de: https://github.com/spring-projects/spring-petclinic

## Requisitos previos

> [!NOTE]
> Ante cualquier duda, selecciona código y pide a Copilot Chat que lo explique.

Necesitarás:

- Una cuenta de GitHub con acceso a GitHub Copilot
- IntelliJ IDEA (Community o Ultimate)
- Git
- Java 17+
