# GitHub Copilot para JetBrains Workshop

Este repositorio es un taller práctico para aprender GitHub Copilot **en IntelliJ IDEA** (Copilot for JetBrains), utilizando la aplicación **Spring PetClinic**.

Los materiales del taller se encuentran en [workshop/README.md](workshop/es/README.md).

## Estructura del repositorio

- [workshop/](workshop/es/) — instrucciones del taller y prompts reutilizables
- [.github/copilot-instructions.md](.github/copilot-instructions.md) — ejemplo de instrucciones de Copilot que puedes copiar en tu clon de PetClinic

## Requisitos previos

- Una cuenta de GitHub con acceso a GitHub Copilot
- IntelliJ IDEA (Community o Ultimate)
- Git
- Java 17+

## Inicio rápido (ejecutar la aplicación)

Clona Spring PetClinic y ejecútalo:

- `git clone https://github.com/spring-projects/spring-petclinic.git`
- `cd spring-petclinic`
- macOS/Linux (y Git Bash en Windows): `./mvnw spring-boot:run`
- Windows (PowerShell): `.\mvnw.cmd spring-boot:run`

Luego abre http://localhost:8080.
